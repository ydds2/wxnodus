# TUI 重构台账（2026-08-29 · wxn-tui-LIVE.html 落地持续版）

> **目标（用户裁决，长期有效）**：依据 `docs/ui-prototype/wxn-tui-LIVE.html`（59 场景）重构 wxnodus 完整 TUI；
> 输入框与参数固定在 cmd 底部；参考同类 agent CLI（codex/gemini-cli/opencode/kimi-cli/crush/aider）风格元素；
> 简易、干净、最少无效信息。
> **框架裁决（已定型）**：官方 ink 6 + React 19（commit 05274b34——废弃自研 fork 与行式核，用成熟组件）。
> 本台账记录每批落地项：机制参考锚点 + 本仓实现位置 + 与竞品差异（AGENTS.md「参考不抄袭」口径）。

## 一、本轮交付

### 第十三批（2026-08-29 · e2e 真机测试修复批次）

子代理完整 e2e 真机 PTY 测试（报告：docs/tui-e2e-test-report-2026-08-29.md）发现 3 缺陷 + 主会话深挖 1 根因，全部修复：

### T42 窗口底部钉死修正（用户反馈「空壳/输入框未固定」）

- **根因**：钉底实现只把输入区贴在「内容树底部」，而内容贴窗口顶部渲染——内容少时输入框浮在窗口上部。
- **修复**：转录区底部空白填充（Transcript filler 占满 maxRows）+ 固定区行数预算精确化——**整树高度恰 = 终端行数**，
  输入框上沿/键位提示/参数行/下沿细线恒落窗口最后 4 行（绝对行号断言 + 80×24/120×30/basic 三档真机验证）。

### T43 斜杠命令 Enter 语义修复（【高】e2e 缺陷——命令卡在输入框）

- **根因**：Enter 在斜杠菜单有匹配时被「应用选中项」吃掉（必须双回车），后续键入串入旧命令（/model/help → 非命令输入）。
- **修复**：kimi 同语义——↑↓ 导航过菜单 Enter 才应用选中项；未导航 Enter 直接提交本行；Tab 仍补全。
  回归测试：单次 Enter 打开 /model 面板 + 导航后 Enter 应用选中项两用例。

### T44 /help 三页面板接线（【中】e2e 缺陷——面板是死代码）

- **根因**：裸 /help 走命令面文本输出，HelpPanel（快捷/全景索引/联动图谱三页）无任何入口。
- **修复**：submit() 拦截裸 `/help` → toggleHelp() 面板；`/help <命令>` 仍走命令面。

### T45 /undo 重复注册根因（主会话深挖——「没有可撤销的消息」谜题）

- **根因**：`src/commands/ext/sessionCommands.ts`（此前未被检索的 ext 子目录）注册了**规范版 /undo**
  （软归档回滚 + /undo fs 文件级 + 自动 checkpoint），后注册覆盖了 handlers.ts 的重复实现——注册顺序陷阱。
- **修复**：删除 handlers.ts 重复注册，ext 版为规范实现；测试重写为软归档语义（archived=1 仍可检索 +
  checkpoint 自动快照 + /undo fs list｜restore）；TUI 回滚面板文案同步（软归档/快照 restore）。

### T46 布尔设置口径统一（【低】e2e 缺陷——开关不可逆）

- **根因**：setSetting 存 String(!on)（字符串），回读 === true 恒假——thinking/voiceAutoSpeak 开关不可逆。
- **修复**：布尔项存布尔（setSetting 类型放宽 string | boolean）；回读兼容历史字符串值。

### 第十批（2026-08-29 · 计划提案批次）

### T39 计划提案批准流（原型 06 · G1 销项——内核零工具闸 + 紫罗兰提案面板）

- **内核硬闸（行为新增，headless 不受影响——桥/面板仅 TUI）**：
  - `mode==='plan'` → **工具面为空**（toolList=[]——模型只出提案文本）；
  - `executeTool` 硬闸：即使模型幻觉出 tool_call 也**零执行**（拦截发生在事件发射前），
    回填「计划模式零工具执行」引导文案；阶段心跳「计划模式：提案中（批准前零工具）」。
  - 非 plan 模式行为不变（全量套件验证）。
- **TUI 实现**：plan 模式回合完成 → 紫罗兰计划卡（原型 06 同款）：计划摘要 + Enter 批准 /
  E 编辑计划（多行编辑器 Shift+Enter 换行）/ Esc 返回（计划保留不执行）；
  **批准 = 切回 smart + 「按上述计划开始执行」重发**（计划已在会话上下文——内核继续执行）；
  编辑 = 以修改后的计划执行；返回 = 诚实提示重发路径。
- **与竞品差异（如实）**：批准/编辑后不保留 plan 档（切 smart 执行）——与原型 06「批准才动手」语义一致；
  「E 编辑」以全文替换式编辑（非行内 diff）——简易优先。

### 第九批（2026-08-29 · 回滚时间线批次）

### T38 回滚时间线（原型 28 · G11 销项——内核 /undo 命令 + 面板双路）

- **内核实现（src/commands/handlers.ts + undoShadows 既有快照链）**：
  - `/undo N`：撤销最近 N 轮——**对话+文件双路**：messages 表分界删除（`deleteMessage` 显式清
    FTS/向量索引——单一实现）+ 每文件取「分界后最早影子」恢复（= 分界时刻现场）；回滚前现状
    再快照（**undo-undo**：/undo fs restore 可再撤销——docs 承诺兑现）；审计落 audit 链。
  - `/undo list`：可撤销回合（run_no 分组 · 时间 · 之后消息数）。
  - `/undo fs list｜restore <编号>`：文件级快照面（Aider /undo 精神的零 git 依赖版——既有能力接命令面）。
- **TUI 实现**：裸 `/rewind` 或 `/undo` → 回滚时间线面板（user 消息时间线 + **影响统计先行**：
  「回滚将丢弃其后 N 轮」逐行标注 + 双路说明）；Enter → 二次确认（危险橙）→ `/undo N` 命令面执行；
  空会话诚实空态（/undo fs 仍可用）。
- **与竞品差异（如实）**：无 fork 分支键（内核 /fork 未接入会话消息面——面板仅提示命令面）；回滚粒度
  = 轮次（run_no）而非消息——与 Claude Code /rewind 快照粒度对齐语义、实现原创。

### T37 压缩三选桥（原型 32 · G10 销项）

- **参考机制**：gemini ContextUsageDisplay 阈值触发 + 三级压缩（原型 32 三选语义——micro 推荐/全量/不压缩）。
- **内核增量（行为保留）**：`AgentRunOptions.onCompactChoice` 桥——上下文超阈值且 msgs>10 时，桥存在则

- **与竞品差异**：不新增「压缩完成回滚」按钮——/undo·/checkpoint 命令面已覆盖（G11 内核 /undo 未实现，

### T34 重连进度心跳（原型 12 · G2 部分销项）

- **参考机制**：kimi 重连可见信号（断网/限流时「第 n 次重连」）+ 原型 12「◐ 重连上游… 第 n 次尝试」。
- **内核增量（最小加法，src/kernel/agent.ts）**：瞬时失败退避循环发出结构化 `agent.retry

- **TUI 实现**：`agent.retry` → store.retry → 心跳行实时倒数 `◈ 重连上游 · 第 n/m 次 · Xs`
  （1s tick 驱动）；`agent.token {reset}` 重发成功即退场；错误出路追加「已自动重试 N 次仍失败」（诚实）。
- **与竞品差异**：不做「面板内手动重试按钮」——原话召回（Ctrl+↑）即重发通道（原型 12 三出路之一），
  与内核自动重试语义不重复；G2 至此收敛为纯展示项已全落地，**销项**。
