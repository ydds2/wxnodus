# 任务 10：整数表达式求值

实现一个纯函数 `evalArith(expr)`：求值整数算术表达式字符串，返回整数。

规则：
- 支持 `+` `-` `*` `/` 与括号 `()`；数字为非负整数；`/` 为整数除法（向零截断，如 `10/3 = 3`、`-10/3 = -3`）；
- 标准优先级：括号 > `*` `/` > `+` `-`；同级从左到右；
- 一元负号只允许出现在表达式最开头（如 `-3+5`）；不含空格；
- 输入保证合法（无需校验非法输入）；不保证整除（靠向零截断）。

示例：
- `evalArith('1+2*3')` → `7`
- `evalArith('2*(3+4*5)')` → `46`

要求：
- 实现写入 `solution.mjs`（导出 `evalArith`，node 可直接执行）；
- 禁止第三方包（不得用 `eval`/`Function` 动态执行）；
- 自测：`node verify.mjs`。
