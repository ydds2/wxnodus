# 任务 8：日期间隔天数

实现一个纯函数 `daysBetween(a, b)`：计算两个 ISO 日期（`YYYY-MM-DD`）之间相隔的整天数。

规则：
- 返回 `b - a` 的天数（含 `a` 当天、不含 `b` 当天）：同一天 → `0`，`b` 在 `a` 之后 → 正数，`b` 在 `a` 之前 → 负数；
- 正确处理闰年（2024 为闰年，2023/1900 非闰年）；
- 输入保证是合法日期。

示例：
- `daysBetween('2024-01-01', '2024-01-03')` → `2`
- `daysBetween('2024-02-28', '2024-03-01')` → `2`（闰年）

要求：
- 实现写入 `solution.mjs`（导出 `daysBetween`，node 可直接执行）；
- 禁止第三方包；
- 自测：`node verify.mjs`。
